# Main Agent 颜色意图与 Memory Agent 真实握手

> Generated by dsh-project-memory as a **proposal**. It is not an approved specification
> and no authoritative document was modified. A human must review and merge it.

## Summary

实现已从“颜色仅参与本地候选排序”推进到显式 Task Intent → 共享 recallForStep → 现有 Router delegate 的真实握手。原 spec 的本地 memory_intent、未使用 categorySelection 配置与 category_id 未保留均已偏离当前实现。请审查此协议精简与候选颜色语义。
